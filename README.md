# 📚 Gerenciamento de Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em **Java**, criado com o objetivo de praticar e consolidar conceitos fundamentais da linguagem e de Programação Orientada a Objetos.

O projeto permite realizar o cadastro, listagem e busca de livros por meio de uma aplicação executada no terminal.

Este projeto faz parte do meu processo de aprendizado em **Java e desenvolvimento de software**, sendo utilizado como projeto de portfólio para demonstrar minha evolução na programação.

---

## 🚀 Funcionalidades

Atualmente, o sistema possui:

* 📖 Cadastro de livros
* 📋 Listagem de livros cadastrados
* 🔎 Busca de livros
* 🏷️ Cadastro de informações como:

    * Nome do livro
    * Nome do autor
    * Código do livro
    * Gênero
* 🖥️ Menu interativo executado pelo terminal
* 💾 Armazenamento dos livros durante a execução da aplicação

## ▶️ Como executar

### Pré-requisitos

Para executar o projeto, você precisa ter instalado:

* **Java JDK**
* Uma IDE Java, como o IntelliJ IDEA

### 1. Clone o repositório

```bash
git clone https://github.com/DanielAugdev/Gerenciamento-de-Biblioteca.git
```

### 2. Acesse a pasta do projeto

```bash
cd Gerenciamento-de-Biblioteca
```

### 3. Abra o projeto no IntelliJ IDEA

Abra a pasta do projeto no IntelliJ IDEA e localize a classe:

```text
Biblioteca.java
```

### 4. Execute a aplicação

Execute o método:

```java
public static void main(String[] args)
```

O sistema será iniciado no terminal e apresentará o menu de opções.

---

## 💻 Exemplo de funcionamento

Ao iniciar o sistema, o usuário encontra um menu semelhante a:

```text
1 - Cadastrar Livro
2 - Listagem Livro
3 - Busca Livro
4 - Sair
```

A partir do menu, é possível cadastrar e consultar os livros durante a execução da aplicação.
